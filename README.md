# Student's Result Summary
This project is an HTML-based Student Result Summary website.
It contains a result summary table with student details and individual marksheets.The "Details" links allow users to view the complete marksheet of each student.
## Files
- index.html - Student's Result Summary
- ahmed.html - Ahmed's Marksheet
- ali.html - Ali's Marksheet
- aisha.html - Aisha Khan's Marksheet 
- usman.html - Usman's Marksheet
## Technologies Used
- HTML5
## Project Purpose
This project was created as part of my HTML assignment to practice tables, links, headings, and structured HTML documents.
